This repository will document how Bitcoin Dominicana developed, using dated
sources, public records and primary evidence.

Documented facts are kept separate from analysis and inference. Every entry
carries its source and an evidence state.

## Evidence states

```
VERIFIED            dated, accessible, checked source
TO VERIFY           data held, source or date not yet confirmed
NOT DEMONSTRATED    not enough evidence to support the claim
```

## One rule

A publication date, a domain registration or the earliest trace located so far
is not read as a founding date. Each is recorded as what it is, and nothing
more.
