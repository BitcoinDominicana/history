This repository documents how Bitcoin Dominicana developed, using dated
sources, public records and primary evidence.

Documented facts are kept separate from analysis and inference. Every entry
carries its source and an evidence state.

**Work in progress.** The timeline is published as it is researched, not once
it is finished. New sources can extend it, change a state or contradict what is
already here. Nothing is removed when that happens: the state is corrected and
the change stays visible in the commit history.

## Evidence states

```
VERIFIED            dated, accessible, checked source
TO VERIFY           data held, source or date not yet confirmed
NOT DEMONSTRATED    not enough evidence to support the claim
DISCARDED           contradicted by the available evidence;
                    not to be used as historical fact
```

`NOT DEMONSTRATED` and `DISCARDED` are not the same. The first means we have
not proved it yet. The second means the evidence argues against it.

## Estados de evidencia

```
VERIFICADO          fuente fechada, accesible y comprobada
POR VERIFICAR       tenemos el dato, falta confirmar fuente o fecha
NO DEMOSTRADO       no hay evidencia suficiente para sostenerlo
DESCARTADO          contradicho por la evidencia disponible;
                    no debe usarse como hecho histórico
```

`NO DEMOSTRADO` y `DESCARTADO` no son lo mismo. El primero significa que
todavía no lo hemos probado. El segundo, que la evidencia va en contra.
